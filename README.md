# Algorithm-Problem-Codes

My solutions to algorithm and competitive programming problems, written
2021 to 2024. About 700 source files, almost all C++, with a few in C and
Python. Many files carry comments (in Chinese) on the approach and its
complexity.

| Directory | Source |
| --- | --- |
| [`leetcode/`](leetcode) | LeetCode problems by number, plus weekly, biweekly and team contest rounds (`week*`, `double_week*`, `spring_contest`, `2022spring_team`) |
| [`week299/`](week299), [`week365/`](week365), [`week369/`](week369), [`mock1/`](mock1) | More LeetCode contest rounds and a mock contest |
| [`Luogu/`](Luogu) | Luogu |
| [`CodeWars/`](CodeWars) | Codewars |
| [`CODIA/`](CODIA) | CODIA |
| [`PTA/`](PTA) | PTA (Programming Teaching Assistant) |
| [`USTCOJ/`](USTCOJ) | USTC online judge |
| [`POJ/`](POJ) | Peking University online judge |
| [`bdaa/`](bdaa) | Hamming code exercise |
| top level | Standalone algorithms: FFT, extended Euclid and the Chinese remainder theorem, arbitrary-precision powers, and a few LeetCode problems |

Each file is a self-contained program. Compile one with, for example:

```bash
g++ -std=c++17 -O2 leetcode/1.cpp -o a.out
```
